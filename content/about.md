I'm MD Naved Raja Khan, a security researcher and systems programmer, and a B.Tech CSE student (graduating 2027) from India.

**What I do:** build low-level security tools, then measure what they miss. Tephra is a runtime security sensor for Kubernetes (eBPF in C, an agent in Go). Fulgurite is a decompiler in Rust. logsift rebuilds an attack timeline from raw logs, sentinel-detections is a set of KQL rules that must pass tests before they count, and reconforge turns recon into a report.

**Practice:** Hack The Box (Skilled), because the fastest way to find a detection rule's blind spot is to think like the person avoiding it.

**Background:** C, Go, Rust, Python, Bash; Linux daily for 4 years; Kubernetes, Docker, AWS and Terraform.

**Looking for:** security engineering, detection and research roles.
